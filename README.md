# 📈 A/B Test for Revenue Optimization

> A data analysis project focused on prioritizing business hypotheses and evaluating A/B test results to optimize revenue through data-driven decision-making.

---

# 📖 Project Overview

A/B testing enables organizations to validate business ideas before implementing them at scale. This project analyzes growth hypotheses and evaluates the results of an online experiment to determine whether proposed changes improve business performance.

The project combines hypothesis prioritization using the RICE framework with statistical analysis of A/B test results to support product and marketing decisions.

The objectives of this project were to:
